# Smart Time Coach

## AI-Based Activity Timer & Goal Progress System

Smart Time Coach is a Java desktop application designed to help users manage their time, track activities, set goals, and monitor their progress.

## Features

- Activity time tracking
- Start, Pause and Stop timer
- Goal creation and management
- Activity/session data storage
- Goal progress tracking
- AI assistance through Ask AI
- SQLite database integration
- Java Swing/AWT graphical user interface

## Technologies Used

- Java
- Java Swing / AWT
- JDBC
- SQLite
- Maven
- AI API

## Project Purpose

The main purpose of Smart Time Coach is to help users understand how they spend their time and improve productivity through activity tracking, goal management, and AI assistance.
